# 区块链项目跟踪档案

> 用途：记录本会话中提交的区块链项目、来源核查、阶段性判断与后续更新。项目方口径不等于独立证实；涉及融资、用户、节点、收入和代币的数据须标注证据等级。

## 分析框架

- **项目定位**：解决什么问题，客户和付费方是谁。
- **产品与机制**：已经上线什么，链上/链下部分如何协作。
- **团队与融资**：创始人背景、金额、轮次、投资方及是否有交叉验证。
- **代币**：状态、用途、供应与解锁、价值捕获、空投/TGE。
- **数据与采用**：活跃用户、节点、客户、收入；区分项目方口径和可验证数据。
- **竞争格局**：直接竞品、差异化、护城河。
- **催化剂与风险**：未来 3–12 个月事件、证伪条件和操作风险。
- **跟踪结论**：观察 / 值得深挖 / 高风险 / 排除，并记录判断日期。

## Perceptron Network

**首次记录**：2026-08-01  
**赛道**：去中心化 AI 数据、DePIN、数据标注/验证、带宽共享  
**前身/整合**：BlockMesh 于 2025-06-19 宣布并入 Perceptron Network。  
**当前评级**：观察，偏高风险早期项目  
**置信度**：中低

### 1. 一句话定位

通过浏览器扩展/节点贡献闲置带宽以采集和结构化公开网络数据，再叠加人工 Data Quests、同行验证与信誉激励，把数据集出售或交付给 AI 公司。

### 2. 已知信息与证据等级

| 报道投资方 | Sigma Capital、Selini Capital、QCP Capital、P2 Ventures、CoinDCX Ventures、Momentum6、DeFi Capital、Walrus Foundation、Aethir、Colosseum、GuruDev Capital、Tempo Finance、NewTribe Capital、Digital Consensus Fund、CodeCraft Capital | B：同上 |

证据等级：A＝官方原始材料；B＝可信媒体或投资方二次确认；C＝项目宣传/未审计口径；D＝社区传言。

### 3. 商业逻辑

- **供给端**：大量个人节点共享 IP/带宽，采集公开数据；贡献者参与文字、图像、语音等数据任务和验证。
- **加工层**：清洗、结构化、标注、同行验证与信誉评分。
- **需求端**：AI 公司、研究机构或数据市场购买特定数据集/实时数据流。
- **激励层**：贡献者获得积分、信誉或未来 $PERC；高信誉可能解锁更高价值任务。

真正决定价值的不是节点总数，而是：可用节点率、地域/IP 分布、单位数据成本、任务完成质量、企业复购率和数据销售收入。

### 4. 正面因素

- AI 数据供应是真实需求，尤其是实时、地域化、小语种及人工验证数据。
- BlockMesh 带来了现成的分布式节点基础，冷启动优于从零搭建。
- 650 万美元若到账，可支撑产品和奖励基础设施迭代。
- 投资名单包含 QCP、Selini、CoinDCX Ventures、Aethir、Walrus Foundation 等产业/加密机构；但需逐家确认公告。
- 由“纯挂机带宽”转向“数据任务＋验证＋信誉”比单纯节点数量叙事更容易形成付费产品。

### 5. 核心风险

- **节点虚胖**：安装量、注册量、在线节点和有任务产出的节点可能差异巨大。
- **需求端不透明**：尚缺公开客户、合同金额、数据销量、收入及复购数据。
- **数据合规**：公开网页抓取仍可能触及网站条款、版权、个人信息、数据库权利和地域监管。
- **代理网络风险**：共享家庭 IP/带宽可能被用于爬取受限内容；节点用户需评估隐私、网络滥用和封禁风险。
- **数据质量/Sybil**：奖励驱动容易产生机器人、重复数据、伪造标签，需要证明验证机制有效。
- **代币价值捕获不清**：若企业收入不需要购买/消耗 $PERC，代币可能只是补贴工具。
- **路线图兑现**：官网把核心 Data Questing v1 放在 2026 Q3，说明完整商业闭环仍在早期。
- **融资确认不足**：当前未检索到项目方或主要投资方对本轮融资的完整独立公告。

### 6. 竞品参考

- Grass：带宽/数据采集网络，节点与数据货币化叙事相近。
- Vana：用户拥有的数据 DAO 与 AI 数据流动性。
- Sahara AI、OpenLedger：AI 数据、模型和贡献者归属/激励。
- Sapien、Kaito 等：人工数据标注、信息或注意力贡献激励（具体业务并非完全同类）。
- 传统数据供应商与标注公司：Scale AI、Appen、TELUS Digital 等，是需求端交付能力的现实基准。

### 7. 后续必须验证

1. 项目方和至少两家核心投资方是否发布 650 万美元融资公告。
2. 融资属于股权、SAFT、代币认购还是混合结构；估值及代币折扣。
3. $PERC 是否已 TGE、链和合约地址、总量、分配、解锁与做市安排。
4. 80 万节点中 7/30 日活、独立设备、地域分布及真实任务完成量。
5. 付费客户、数据订单、ARR/收入、毛利和复购率。
6. 节点软件是否开源、权限范围、安全审计和流量滥用防护。
7. Data Questing v1 实际上线时间、任务量、贡献者收入与验证准确率。
8. 从 80 万扩到 500 万节点的必要性：是否有足够的客户需求消化供给。

### 8. 阶段性判断

项目处在“有大规模分发网络，但商业闭环尚未证明”的阶段。融资与 AI 数据赛道带来关注度，BlockMesh 的既有节点是它相对普通 AI+Crypto 项目的优势；最大疑问是节点是否产生可售数据，以及企业是否持续付费。现阶段适合跟踪产品和代币信息，不适合只依据节点数或融资名单作重仓判断。

## Dolphin（POD）

**记录日期**：2026-08-23（Asia/Shanghai）  
**网络/合约**：Base，`0xed664536023d8e4b1640c394777d34abaff1df8f`  
**CoinGecko ID**：`dolphin-2`  
**当前评级**：高风险观察；适合已有闲置合规 GPU 小规模实测，不建议仅为 POD 新购或长租 GPU

### 1. 定位与近况

Dolphin 是去中心化 AI 推理及数据生成网络。矿工运行 GPU worker，按实际完成的推理 token 获得 POD；不是固定区块奖励的 PoW，也不是开机即有稳定收入。项目已从 DPHN 迁移并更名为 POD，需只认上述新合约。

项目近期自报：Qwen 3.6 35B 数据生成累计 228 亿 token、383 张 GPU 在线、总显存 24.33TB；此前首个奖励 epoch 向 33 个 provider 发放 5 万 POD。均为项目方口径，未独立审计，且早期 epoch 补贴不可直接外推。

### 2. 市场快照

CoinGecko 2026-08-23 23:44 左右：POD 约 $0.5024，24h +12.09%，7d +65.76%，30d -2.07%；流通市值约 $2,196 万，FDV 约 $2.512 亿，24h 成交额约 $179 万。流通约 4,371 万枚，占 5 亿总量约 8.74%；FDV/流通市值约 11.4 倍。历史高点约 $0.6102（2026-07-26），距高点约 -17.7%。

当前可见交易场所包括 Hibt、LBank、Ourbit，以及 Base 上 Uniswap v4、Aerodrome；Poloniex 曾于 2026-05-12 公告上线，当前实际交易状态需到交易所复核。尚未见 Binance、Coinbase、OKX、Bybit、Kraken 等一线现货上市。

### 3. 矿机与结算

官方当前完整模型约需 70GB VRAM，列出的配置包括：1×RTX PRO 6000、1×H100/A100 80GB、4×RTX 3090/4090、2×RTX 5090、2×A6000/L40 等。中国市场常见 RTX 5090D V2 仅 24GB，2 张只有 48GB，不能把它等同于官方 32GB 5090 配置。

V100 32GB 虽可用 4/6/8 卡组成 128/192/256GB 物理显存，但当前不属于官方列出的节点配置。V100 为 compute capability 7.0，而 Dolphin 采用的当前 Sonar 官方预编译 NVIDIA wheel 要求 compute capability 8.0+；因此默认 worker 很可能无法运行。只有项目方提供包含 `sm_70`、FP16 路径和相应验证内核的兼容镜像后才可实测，其中 4/8 卡比 6 卡更符合常见 tensor-parallel 切分。不能仅凭总显存判定可挖。

官方当前 datagen 基准为每 100 万推理 token 发放价值 $0.5 的 POD，收益随真实需求浮动。按 POD=$0.5024，约为 0.995 POD/百万 token；3 个月收益额对应的 bonding 可线性提升至 1.2×，竞争性超额 bonding 最高 1.3×。满足条件后若直接领取流通 POD，需向 staker 支付 20% fee；首月收益只以 bonded POD 形式获得。

加入步骤：访问 `https://v2.dphn.ai`，连接钱包，创建 API key，进入 Worker Link 复制安装脚本，在 Linux GPU 服务器执行；用 `./dolphinpod-worker logs` 检查，出现 `connected to lighthouse` 才算连通。

### 4. 粗略经济性（非收益承诺）

根据项目方约四周内累计 token 从 32 亿升至 228 亿推算，全网日增约 7.0亿至7.84亿 token；按 $0.5/百万 token，相当于全网约 $350–392/日。若简单除以当前 383 张 GPU，只是约 $0.91–1.02/GPU·日。个体会因显卡、吞吐、在线率和任务分配严重偏离此均值。

仅电费盈亏线（按 ¥0.60/kWh）：4×4090 整机约 2.0–2.1kW，约 ¥29–30/日，需要约 800 万 token/日才能覆盖电费；2×5090 整机约 1.3–1.45kW，约 ¥19–21/日，需要约 560 万 token/日；单 RTX PRO 6000 整机约 0.75–0.9kW，约 ¥11–13/日，需要约 320 万 token/日。云租 A100 若约 $1.39/小时，单日租金 $33.36，需要约 6,670 万 token/日才能仅覆盖租金。

结论：已有闲置设备可跑 7–14 天实测每卡 token、有效在线率及真实到账；没有机器时，不应按首个 epoch 的 5 万 POD 或社区晒图采购。采购门槛应至少是实测连续 4 周后，净收入覆盖电费、托管、故障和三年折旧。

### 5. 代币与风险

- 总量 5 亿：Treasury 42.93%、团队 25%、Seed 23.52%、Uniswap v4 池 8.55%。流通比例低，潜在稀释显著。
- Seed 约 1.176 亿枚已过 2025-06-20 的一年 cliff；解锁不等于已流通，但构成潜在供给。
- 团队为至少两年 cliff 后十年线性；2025 年另有约 425 万枚 OTC，带 cliff 与线性释放。
- CoinGecko 引述 GoPlus 警告：合约创建者可能修改交易行为，例如限制卖出、修改费用、增发或转账规则。必须核验管理员权限、升级权和多签状态。
- 主要流动性集中在少数 Base 池和二三线 CEX；成交量与可退出深度不能只看名义市值。
- 奖励来自 treasury 且随需求浮动；若真实 API 客户不足，矿工收入可能长期低于硬件与电力成本。

### 6. 后续监控

每周记录 POD 价格/市值/FDV、流通量变化、DEX 池深、CEX 上下架、奖励 epoch 总额和参与 GPU 数；矿端必须记录机器配置、有效 token/日、POD 到账、bonding 状态、功耗与电费。只有“每台机器真实 token/日”可用于回本模型，项目累计 token 和在线 GPU 数只能做粗略旁证。

## BTX Chain（BTX）

> **固定识别规则**：用户在本会话及 mining/项目分析中提到 `BTX`，一律指 `btx.dev` 的 BTX Chain。后续回答不再主动提及其他同代码项目，除非用户明确要求辨伪或对比。

**记录日期**：2026-08-24（Asia/Shanghai）  
**官网**：https://btx.dev/  
**代码**：https://github.com/btxchain/btx  
**当前评级**：极高风险观察；协议研发活跃，但主网尚未证明连续稳定，暂无可执行公开市场

### 1. 项目定位

2026-03-19 启动的独立 PoW 主链，最大供应量 2,100 万，目标 90 秒区块，单块奖励 20 BTX。核心叙事是 512×512 M31 MatMul 工作量证明、ML-DSA/SLH-DSA 后量子转账、P2MR 地址以及未来的隐私和分层结算。

### 2. 主网状态

项目在 185,000 高度激活 MatMul v4.7 后经历共识、难度及竞争分叉处理问题。v0.33.3 于 2026-08-17 发布，作为“GPU 验证全节点路径”的第一阶段，并在 191,714 高度设置 ASERT 难度下限；后续仍计划增加 attestor、提高 M，再把 seed 转为 GPU ExactReplay，说明完整目标架构尚未完成。

截至 2026-08-24 23:50 左右，BTXScan 显示主链高度 199,296，最后区块时间 2026-08-24 05:07:51 UTC，已停块约 10 小时 40 分，mempool 18 笔。此前最近十块滚动平均约 2分33秒，但十块中几乎全是 coinbase，仅高度 199,294 含一笔普通交易。因此结论是：链曾恢复推进，但当前再次长时间停块，尚不能认定主网稳定恢复。

### 3. SafeTrade 下架与市场

SafeTrade 曾短期上线 BTX，随后因网络问题维护并永久停止交易。交易所曾公开表示，只要网络仍运行，停止交易后钱包通常至少保持开放六个月；具体提现截止时间必须以账户及交易所最新公告为准。

SafeTrade 下架后，BTXScan、BTX.best 均明确写明 BTX 目前没有公共订单簿。网页展示的数百至数千美元“model/reference price”及数十亿美元“market cap”是模型估值，不是可成交价格，不应计入矿业收入或资产净值。目前只见第三方 OTC/RFQ 页面，存在重大对手方、价差与结算风险。

### 4. 上所计划判断

截至记录日，官方未公布任何具名新交易所、申请进度或上线日期。官网只把“可执行公开价格发现、托管、批发库存和 OTC 流动性”列为未来必须建设的市场基础设施，等于承认这些环节当前尚不成熟。任何“即将上某所”在缺少交易所官方公告前均按传言处理。

新交易所接入的前置条件至少包括：主网连续 30–90 日稳定出块、无深度重组/分叉争议、签名且可复现的正式节点二进制、稳定钱包 RPC 与充值提现、多个独立节点/矿工/浏览器一致、可验证流动性和做市安排。当前 v0.33.3 原生二进制明确标注非 Guix 可复现且未 GPG 签名，主链又再次停块，不利于近期 CEX 技术审核。

### 5. 影响评估

- 对“协议是否仍开发”：不是致命，GitHub 和 8 月版本发布仍活跃。
- 对“币能否交易和定价”：影响极大；唯一可见公共订单簿消失，当前没有可靠现货价格、市值或日成交量。
- 对矿工：影响极大；矿出 BTX 但无法可靠变现，法币收入应按接近零或仅按已成交 OTC 净价确认。
- 对下一家交易所：负面；永久下架和反复停链会提高钱包集成、重组、充值确认及客服成本。
- 对项目生存：短期不等于归零，但项目已经从“技术+市场风险”退化为“技术恢复、流动性和价格发现三重风险”。

### 6. 重点监控

连续记录最新区块时间、24小时出块数、最长停块、非 coinbase 交易数、独立矿工/节点、版本采用率、重组事件；同时只承认交易所官方发布的 listing。主网至少连续 30 天接近90秒目标、无长停块和深重组，才可从“故障恢复”升级为“基本稳定”。

## Autonomys Network（AI3）

**记录日期**：2026-08-25（Asia/Shanghai）  
**官网**：https://www.autonomys.xyz/  
**CoinGecko ID**：`autonomys-network`  
**当前评级**：高风险存量观察；主网和产品仍运行，但币价、farming 规模与交易所流动性严重衰退，不建议为 AI3 新购 SSD

### 1. 定位与产品状态

Autonomys 是基于 Proof-of-Archival-Storage（PoAS）的存储共识链，主网 Phase-1 于 2024-11-06 启动，2025-07-16 在高度 3,585,226 开放转账并进入 Phase-2。农民用 SSD 保存历史数据，按存储占比随机获得出块和投票奖励；GPU只用于初始 plotting/replotting 加速，不参与日常 farming。

当前官网已把重心收敛到永久存储产品 Auto Drive，提供 Web、TypeScript SDK、REST、S3、rclone 和 AI agent/MCP 接口，并允许用 AI3 购买存储 credits。官网快照显示约 182 个在线节点、21.71PB pledged storage、约240ms平均检索、256×复制。产品可用性比纯叙事项目更实，但“永久存储”的长期成本能否由一次性低价收费和代币经济持续覆盖仍待验证。

### 2. 市场快照与交易所

CoinGecko 2026-08-25 快照：AI3 约 $0.00136，24h +7.1%，7d +22.6%，市值约 $14.9 万，FDV约 $91.4万，24h成交约 $1.35万；流通约1.098亿，总供应约6.722亿，最大10亿。ATH为 $0.08785（2025-08-27），当前约低98.5%。

### 3. Farming 硬件

官方最低：4核CPU、8GB RAM、100GiB节点盘、100GiB farm；推荐 i7-6700同级或更高、16GB RAM、256GB节点盘。farm必须使用 SSD，HDD因随机读取IOPS不足明确不支持；普通中端SATA SSD即可，NVMe不是必须。支持Windows 11、Ubuntu和macOS，可用Space Acres GUI或CLI/cluster。稳定不限流量网络是必要条件。

GPU不参与持续 farming，只缩短plotting；因此不能按GPU矿币估算。收益与有效SSD空间占全网21.71PB的比例相关，并带明显随机性。Standard模式约99%空间计入奖励，1%保留本地piece cache；cluster模式可计100%。

### 4. 收益与经营判断

2024-11项目曾宣布超过300PB、2,000+ farmer nodes；当前官网仅显示21.71PB、182节点，按相同口径约下降92.8%空间和90.9%节点。可能包含统计口径变化，但与币价从ATH下跌98.5%及多所下架方向一致，表明大量农民退出或网络显著收缩。

总供应相对创世约6.5亿增加约2,217万枚，按主网上线以来粗略平均约3.4万AI3/日；若以当前21.71PB简单均分，约1.6 AI3/TB·日、按现价仅约$0.0022/TB·日。动态发行、实际空间、投票数和运气会使真实值偏离，必须以Space Acres真实到账及社区calculator为准。这一数量级通常不足以覆盖新SSD折旧，甚至可能低于整机待机电费。

结论：已有闲置且健康的SSD可以低成本试跑；不应为AI3购买企业盘、NVMe阵列或新服务器。账务上按可实际在XT或已验证交易所卖出的净价确认收入，不能按薄盘口显示价给大额库存估值。

### 5. 主要风险与观察点

- 主网比BTX稳定、产品也已上线，但 permissionless operator 仍未在主网开放，当前operator由Subspace Foundation许可运行，执行层中心化程度较高。

- 网络规模较早期峰值大幅收缩，需核实是口径调整还是矿工真实退出。
- 永久存储定价极低：官网套餐价格换算与当前AI3币价并不同步，需要关注credits、销毁/费用归属、真实付费上传量和协议收入。
- 后续只有重新获得至少两家可靠交易所、恢复深度、节点与pledged space企稳、真实存储需求增长，才考虑提高评级。

### 1. 项目定位与阶段

Darkbloom 是 Eigen Labs 于 2026-04-15 公布的研究项目，把 Apple Silicon Mac 的统一内存和 GPU 接入 OpenAI/Anthropic 兼容的私密推理网络。用户按 token 付费，协调器把请求路由到提供者 Mac，提供者通过 MLX 本地推理。项目仍标注 Public Alpha、evaluation use only、未经审计，并明确可能发生中断和破坏性升级。

它没有官方 Darkbloom 代币，也没有钱包、链上充值或交易所上市。消费者通过 Stripe 向内部 micro-USD 账本充值，提供者通过 Stripe Connect 收美元；公测期平台费为 0%，提供者保留 100% 的 token 收入。市场上的同名代币不能据此认定为官方资产。

### 2. 2026-08-26 实时网络快照

公开证明接口的另一次快照列出约1,148台设备，其中296为serving、788为online、64为untrusted，硬件证明约1,010台。主流内存为64GB（294台）、32GB（225台）、128GB（156台）和48GB（146台），供给端已经有明显竞争。

- 主网上线仅一天，难度、全网算力、矿池幸运值和单位算力产出可能快速变化。
- PPLNS 单日波动较大；矿池官方也提示一小时幸运值可令结果偏移约10%，应以更长周期比较。
- `quanpool-hive` 是矿池定制版本，且Quantus官方尚未验证任何第三方矿池运营商；须持续关注支付记录、升级来源、费用及二进制完整性。
- SafeTrade虽已上市QUAN，但上线初期价格与深度可能剧烈波动；最大的经营风险仍包括流动性、定价和兑现能力。
